Ads after returns

Meta only ever hears about the purchase, so it keeps scaling the ads that sell the most, including the ones that sell the wrong expectation. Here each ad is scored on revenue the business keeps.

Commuter and Voyager ads, last 30 days Sample
AdMatched byROAS: reported vs keptReturnedRTOTop return reasonSuggested action

Kept-revenue ROAS = Meta-reported ROAS × (1 − return rate − RTO rate). Three limits: the two rates are measured on slightly different bases (delivered vs all orders); Meta's own attribution (7-day click, 1-day view) already credits Meta with more orders than Shopify can trace, so this figure is still optimistic; and reverse pickup, repacking and seconds markdowns are not subtracted yet. Use it to rank ads against each other, not as a P&L number.

How each ad gets matched to its returns

  • 1Creator codes (RIYA15, ANANYA15) already sit on the Shopify order. The cleanest signal you have.
  • 2Ad ID in the link: add utm_content={{ad.id}} to every Meta ad from day one so even non-code orders carry the ad. Past orders stay partly unmatched: only about 40% of Shopify orders have a source today.
  • 3Post-purchase survey as a fallback, with "Instagram" and "Influencer" split into "an ad" and "a creator I follow".
  • 4Order ID then links to Farhan's weekly returns sheet and the reason from the return flow.

    How it connects

    No new system to run. The pieces Breltz already has are joined on the order ID, and the result changes three things: which ads get scaled, what ads and listings are allowed to say, and what Meta learns.

    Who owns what

    Sneha

    Kept-revenue ROAS and the scaling rules. Approves only creatives that pass the claim check.

    Pooja

    Return flow and save rate. Ticket reasons now arrive tagged with the order ID.

    Farhan

    Keeps the weekly sheet; QC grade joins automatically. Fewer bags back, less stock stuck in reverse transit.

    Aditya

    Monday review on numbers. Owns the free-returns decision with the real return cost in view, compared season for season so Diwali gifting returns are not mistaken for a policy effect.
